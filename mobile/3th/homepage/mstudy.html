웹 프로그래밍 학습 기록

  1. 1주 ~ 3주

    HTML 기본 구조와 태그

    제목, 문단, 목록, 표, 이미지, 링크 태그를 익히고 문서 구조를 잡는 방법을 배웠습니다.

  2. 4주 ~ 6주

    CSS 스타일과 레이아웃

    선택자, 박스 모델, 색상과 글꼴, flexbox와 grid로 화면을 배치했습니다.

  3. 7주 ~ 9주

    반응형 웹과 미디어 쿼리

    브라우저 창 너비를 기준으로 배경색과 배치가 바뀌는 페이지를 만들어 보았습니다.

  4. 10주 ~ 현재

    포트폴리오 사이트 제작

    여러 페이지를 하나의 공통 CSS로 묶어 관리하는 방법을 실습하고 있습니다.
