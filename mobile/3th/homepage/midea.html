도서와 영화 웹 프로젝트 아이디어 5선

10주 이상 혼자 진행하는 기말 프로젝트를 기준으로 고른 아이디어입니다. 서버 없이 브라우저 저장(localStorage)만으로 완성할 수 있도록 범위를 잡았습니다.

도서보통

나의 독서 서재

책을 검색해 내 서재에 담고, 읽은 기록과 독서 통계를 한눈에 보는 개인용 독서 서비스입니다.

  • HTML
  • CSS
  • JavaScript
  • 도서 API
  • Chart.js

핵심 기능

  • 도서 API로 표지, 저자, 소개글 검색
  • 읽고 싶은 책, 읽는 중, 다 읽음으로 분류
  • 별점과 한 줄 리뷰 작성, 수정, 삭제
  • 월별 독서량을 차트로 표시

페이지 구성

메인, 검색, 책 상세, 내 서재, 통계

발표 포인트

서재에 담은 책이 새로고침해도 남고, 통계 차트가 실제 기록으로 그려지는 장면을 시연합니다.

영화안정

영화 다이어리

본 영화를 날짜와 함께 기록하고, 달력과 통계로 나의 관람 습관을 돌아보는 서비스입니다.

  • HTML
  • CSS
  • JavaScript
  • localStorage
  • Chart.js

핵심 기능

  • 관람일, 극장이나 OTT, 별점, 감상 메모 기록
  • 기록 수정과 삭제, 장르와 별점 필터
  • 달력에서 관람일 확인
  • 연간 관람 편수와 장르 비율 통계

페이지 구성

메인, 기록하기, 기록 목록, 달력, 통계

발표 포인트

달력의 관람일에 포스터 썸네일이 표시되는 화면으로 시각적 완성도를 보여 줍니다. 포스터는 이미지 주소를 입력해 표시합니다.

영화도전

영화 탐색과 찜 목록

영화 데이터를 불러와 인기작을 탐색하고, 마음에 드는 영화를 찜해 두는 서비스입니다.

  • HTML
  • CSS
  • JavaScript
  • fetch
  • 영화 API

핵심 기능

  • 인기, 평점순, 개봉 예정 목록
  • 장르 필터와 제목 검색
  • 상세 화면(줄거리, 출연진, 평점)
  • 찜 목록 저장과 삭제

페이지 구성

메인(인기 영화), 탐색, 영화 상세, 찜 목록

발표 포인트

외부 API 연동과 비동기 처리(fetch)를 보여 줄 수 있어 기술 난이도가 드러납니다. 다만 API 키 발급과 출처 표기 조건은 시작 전에 확인해야 하고, 시연용 샘플 데이터도 준비해 두는 것이 안전합니다.

도서와 영화보통

원작과 영화 비교 아카이브

소설을 원작으로 한 영화를 짝지어 놓고, 두 작품의 차이를 나란히 비교해 보는 아카이브입니다.

  • HTML
  • CSS
  • JavaScript
  • JSON
  • localStorage

핵심 기능

  • 원작과 영화 20~30쌍을 직접 정리한 데이터
  • 나란히 비교 화면(줄거리 차이, 출간과 개봉 연도, 평점)
  • 책만, 영화만, 둘 다 봤어요 체크
  • 내가 더 좋아한 쪽 선택과 통계 표시

페이지 구성

메인, 작품 목록, 비교 상세, 내 체크 목록, 선택 결과

발표 포인트

흔한 리뷰 서비스와 주제가 달라 차별점이 분명하고, 외부 API 없이 안정적으로 시연할 수 있습니다. 대신 데이터를 정리하는 시간이 듭니다.

도서와 영화안정

올해의 감상 리포트

읽은 책과 본 영화를 한곳에 기록하고, 연말 결산처럼 요약해 보여 주는 서비스입니다.

  • HTML
  • CSS
  • JavaScript
  • localStorage
  • Chart.js

핵심 기능

  • 책과 영화를 하나의 폼으로 기록
  • 월별 감상 수와 장르 비율 차트
  • 별점 높은 작품 TOP 5
  • 취향을 요약하는 문장 자동 생성

페이지 구성

메인, 기록하기, 전체 기록, 리포트

발표 포인트

리포트 화면에 "가장 많이 본 장르" 같은 요약 문장이 자동으로 나오는 장면이 핵심 시연 포인트입니다.
